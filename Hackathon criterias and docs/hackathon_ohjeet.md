Quanscient: Simulation-powered app
Quanscient
Use Quanscient's Allsolve, a cloud multiphysics simulation engine, to create a web app that runs a real physics simulation for a use case you identify.

Why it matters: engineering simulation usually means one expert working with complex desktop software. The Allsolve SDK exposes that same simulation as code, so anyone can build a custom app for a specific problem. We want to see new use cases, interfaces, and ways to solve and optimize real engineering problems faster.

A great solution: a working app (rough is fine) that takes user input, calls Allsolve via the SDK, runs a real simulation and returns a result the user can act on. The physics must genuinely do the work, not a fake number dressed up in a nice UI. Show the real industry problem it solves. Allsolve access and web app examples are provided. Critically evaluate the SDK's usability and suggest concrete improvements.

Judging criteria

Winning criteria:
1) A meaningful industry problem that provides value for the user.
2) Creativity and originality of the use case.
3) SDK experience and insights: clear usability pain points and improvement ideas.
4) A working demo where the physics is actually used and the logic seems correct.

Prize: one winner, EUR 500.
